# Customer_Behaviour_Analysis
Customer Behaviour Analysis using Python, SQL, and Power BI to extract insights on purchasing patterns, customer segmentation, and sales trends.

# Objectives
-Analyze customer purchase behavior

-Identify top-selling products and categories

-Understand customer segmentation

-Track sales trends and revenue patterns


# Tools & Technologies Used:
1. Python (Pandas, NumPy) → Data Cleaning & Preprocessing

2. SQL → Data Analysis & Querying

3. Power BI → Data Visualization & Dashboard

# Project Workflow
1️⃣ Data Collection
Dataset contains customer shopping behavior data
Includes features like product category, purchase amount, shipping type, etc.

2️⃣ Data Cleaning (Python)
Removed missing/null values
Corrected data types
Handled duplicates
Prepared dataset for analysis

3️⃣ Data Analysis (SQL)
Extracted insights using queries such as:
Top purchased products
Category-wise sales
Customer spending patterns
Shipping type analysis

4️⃣ Data Visualization (Power BI)
Created interactive dashboards showing:
Sales trends
Customer segmentation
Revenue distribution
KPI metrics
